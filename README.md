# Compilação
Compilando máquinas virtuais.

    $ make vms
    $ sh/build_vms all

Para compilar uma em específico, indique um índice de 0-3

    $ sh/build_vms 2

Compilando Bao

    $ make bao
    $ sh/build_bao.sh

Copiando o binário do bao para o cartão SD

    $ make copy
    $ sh/copy.sh?
